# علوم الفنجال

تطبيق PWA لعلامة علوم الفنجال، مخصص لأصحاب الكافيهات في الكويت.

## التشغيل

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
uvicorn app.main:app --reload
```

افتح `http://127.0.0.1:8000`.

## النشر العام عبر Render

1. ارفع المشروع إلى مستودع GitHub.
2. من Render اختر **New +** ثم **Blueprint**.
3. اختر مستودع المشروع، وسيقرأ Render ملف `render.yaml` تلقائياً.
4. اضغط **Apply** وانتظر اكتمال النشر.

سيظهر لك رابط عام بصيغة `https://اسم-الخدمة.onrender.com`.

يعمل الموقع بدون مفاتيح API بوضع العرض المحلي. لتفعيل توليد OpenAI، أضف `OPENAI_API_KEY` من إعدادات Environment في Render، ولا تضع المفتاح داخل الملفات.

## تثبيت التطبيق

افتح الرابط من Chrome أو Edge، ثم اضغط **ثبّت التطبيق** إذا ظهر الزر، أو اختر تثبيت التطبيق من قائمة المتصفح. يعمل التطبيق كتطبيق مستقل ويحتفظ بواجهة الاستخدام الأساسية عند انقطاع الإنترنت.
